# InternScope — Job Market Analytics Dashboard

An interactive analytics dashboard that explores job market trends from 123,849 LinkedIn job postings.

## Features
- Job distribution by role and location
- Top 15 most in-demand skills
- Skills × Role heatmap
- Salary distribution and benchmarks
- ML Insight: Skill Importance Predictor using Random Forest, Gradient Boosting, and Logistic Regression

## Tech Stack
Python · Streamlit · Plotly · Pandas · Scikit-learn · WordCloud

## Data Source
LinkedIn Job Postings via Kaggle
